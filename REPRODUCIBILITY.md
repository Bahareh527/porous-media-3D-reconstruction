# Reproducibility guide

## Maintained examples versus published experiments

The six maintained notebooks run independently on synthetic data. Shared source lives in `src/porous_media/`; choices are explicit configuration/CLI parameters. Older experimental notebooks are excluded from the current repository.

Thesis/publication results have **not** been regenerated by this refactor. Native U-Net/residual U-Net and the shape-inferred hybrid are reference architectures, not exact pretrained-backbone or historical-checkpoint reproductions. See [model decisions](docs/code-review.md).

## Environment and verification

Use dedicated Python 3.11, preferably a short Windows path. Dependency ranges are not a complete lockfile; export exact installed versions for an experiment.

```bash
python -m pip install -e ".[learning,netcdf,notebook,dev]"
python -m pytest
python scripts/check_repository.py
python scripts/audit_notebooks.py
python scripts/execute_notebooks.py
porous-media prepare --config configs/demo.json
porous-media demo --mode segmentation
porous-media demo --mode hybrid
```

Execution uses separate temporary kernels without saving outputs. CPU checks do not establish GPU compatibility, convergence or scientific agreement. CI also checks lightweight installation without TensorFlow (learning tests skip explicitly). Optional OpenPNM/PoreSpy needs its separate backend and physical setup.

## Real data

1. Obtain [external volumes](data/README.md); record provider terms and checksums.
2. Put inputs under `data/raw/`; confirm registration, orientation, axis order and image/label alignment.
3. Copy/edit [Bentheimer configuration](configs/bentheimer.json). Verify NetCDF variables, integer class mapping, pore label, meter-valued voxel size, splits, gaps, patch size and stride. Empty mapping requires already-valid class IDs.
4. Run `porous-media prepare --config configs/bentheimer.json` without writing. Check patch counts and RAM requirements. Whole-volume loading/scaling still needs RAM; patches are stored and training-loaded incrementally.
5. Add `--write` after checking. Paired compressed patches record origins/checksums. Nonempty run folders, including partial runs, cannot be overwritten.

The scaler fits training-only and applies recorded clipping to [-1,1] everywhere. Patch slicing preserves voxel geometry; incomplete trailing training patches are omitted, not resized. Inference covers edges and overlap-averages predictions. Splits do not overlap, but adjacent slices can remain correlated; optional gaps are an experimental choice, not a guarantee of independence.

## Reference training examples

```bash
porous-media train --manifest outputs/bentheimer-128/manifest.json --mode segmentation --output outputs/segment-run --epochs 100 --filters 16 --depth 4 --residual
porous-media train --manifest outputs/bentheimer-128/manifest.json --mode vox2vox --output outputs/vox-run --epochs 100 --filters 64 --depth 4
porous-media train --manifest outputs/bentheimer-128/manifest.json --mode hybrid --output outputs/hybrid-run --epochs 100 --filters 16 --depth 4 --segmentation-checkpoint outputs/segment-run/segmentation.keras --encoder-layer encoder_features --decoder-filters 128 64 32 16
porous-media evaluate outputs/reference.npy outputs/prediction.npy --data-range 2
```

These are new reference examples, not publication hyperparameters. Large filters can exhaust memory. `--binary` selects binary Vox conditioning, `--loss-family` selects BCE/least-squares, and `--l1-weight` is explicit. Hybrid decoder filter count must match the selected encoder downsampling depth.

Finite manifest iterators retain partial final batches. GAN history is sample-weighted; validation does not update parameters. GAN artifacts include both .keras models, optimizer/epoch checkpoints, measured history, configuration and manifest hash. Segmentation stores model, history and configuration. The CLI refuses nonempty runs; programmatic GAN resume uses `GanTrainer.restore` with matching architecture/objective followed by `fit`.

Import `porous_media.models` before loading a generator to register custom layers. Supply a batch-callable generator to `porous_media.inference.predict_volume`; Vox inputs are encoded labels, hybrid inputs normalized grayscale. Reference/prediction must share registration and scaling.

## Reporting and physics

Generated outputs stay ignored. Record commit, full environment export, Python/CUDA, input hashes/terms, split/gap/class mapping, scaler, patch grid, seed, architecture/loss, hardware, checkpoint and measurements. Seeds do not guarantee bitwise equivalence across devices.

For physical evaluation record pore-mask policy and meter-valued voxel size; follow [flow validation](docs/flow-validation.md). Smoke tests do not validate extraction, fluid models, mass conservation on a real sample or thesis permeability curves.
